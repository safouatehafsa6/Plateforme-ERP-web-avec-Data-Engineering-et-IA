VERSION ERP — OCR / DICTÉE / REFORMULATION / MOBILE

1. Décompresser le projet.
2. Conserver le fichier .env livré avec cette archive ; ne pas le remplacer par .env.example.
3. Ouvrir un terminal à la racine du projet.
4. Vérifier la configuration : docker compose config
5. Construire et démarrer : docker compose up -d --build
6. Vérifier les services : docker compose ps
7. Ouvrir l'application : http://localhost:3000

Le backend Docker installe Tesseract et les langues fra/ara/eng.
Le modèle IA attendu est Ollama avec qwen2.5:3b.
Pour le cas où Docker tourne dans VMware et Ollama sur Windows hôte,
lire docs/DEPLOIEMENT_VMWARE_OCR_DICTEE.md avant le démarrage.
